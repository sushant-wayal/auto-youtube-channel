# YouTube Timestamps Implementation Summary

## ✅ Implementation Complete

The YouTube chapter timestamps feature has been successfully implemented with the following approach:

## 🎯 Architecture Overview

### 1. **Script Generation** - Add Scene Titles
- Modified prompt to require `sceneTitle` field for each scene
- Scene titles are short descriptive phrases (3-7 words)
- These titles will be used as YouTube chapter names

**Files Modified:**
- `website/lib/pipeline/script-generation.ts` - Added `sceneTitle` to scene structure
- `website/lib/pipeline/types.ts` - Added `sceneTitle?: string` to `SceneIR` interface

### 2. **Video Assembly** - Track Actual Scene Durations
- Video assembler now tracks the actual duration of each assembled scene
- Durations are based on voiceover audio length (the source of truth)
- Returns `sceneDurations` array alongside the assembled video

**Files Modified:**
- `workers/video-assembler/src/lib/video/video-assembly.ts`:
  - Track `sceneDurations[]` during assembly loop
  - Each scene duration = `max(animationStopTime + 0.5s, voiceoverDuration)`
  - Return `sceneDurations` in result
- `workers/video-assembler/src/index.ts` - Pass through `sceneDurations`
- `.github/scripts/assemble-video.ts` - Output `scene_durations` to workflow

### 3. **Workflow** - Pass Scene Data to Upload
- Assemble-video job now outputs `scene_durations`
- Upload-youtube job receives `scene_durations` via environment variable

**Files Modified:**
- `.github/workflows/main.yml`:
  - Added `scene_durations` output to assemble-video job
  - Pass `SCENE_DURATIONS` env var to upload-youtube job

### 4. **YouTube Upload Worker** - Generate Timestamps
- Created timestamp generator utility
- YouTube upload worker now:
  - Extracts scene titles from script data
  - Receives actual scene durations from assembly
  - Generates formatted timestamps (0:00, 1:23, etc.)
  - Appends chapters to description (for long-form videos only)

**Files Created:**
- `workers/youtube-upload/src/utils/timestamp-generator.ts`:
  - `formatTimestamp()` - Convert seconds to MM:SS or HH:MM:SS
  - `generateTimestamps()` - Create chapter list from titles + durations
  - `canGenerateTimestamps()` - Validate if timestamps can be generated

**Files Modified:**
- `workers/youtube-upload/src/index.ts`:
  - Added `sceneTitles` and `sceneDurations` parameters
  - Generate timestamps for long-form videos only
  - Append to description: `\n\n📚 Chapters:\n{timestamps}`
- `.github/scripts/upload-youtube.ts`:
  - Extract scene titles from script (use `sceneTitle` or fallback to narration)
  - Decode and parse `SCENE_DURATIONS` from environment
  - Pass to `uploadToYouTube()`

## 📊 Data Flow

```
Script Generation
└─> scenes[].sceneTitle  (3-7 word titles)
        ↓
Video Assembly
├─> Processes each scene with voiceover
├─> Tracks actual duration per scene
└─> Returns sceneDurations[]
        ↓
GitHub Workflow
└─> Passes scene_durations to upload job
        ↓
YouTube Upload Script
├─> Extracts scene titles from script
├─> Parses scene durations from assembly
├─> Calls timestamp generator
└─> Appends chapters to description
        ↓
YouTube Upload Worker
├─> Generates timestamps (if long-form video)
├─> Formats: "0:00 - Title 1\n1:23 - Title 2"
└─> Uploads with enhanced description
```

## ✨ Key Features

### ✅ Automatic
- No manual timestamp entry needed
- Generated from actual video durations

### ✅ Accurate
- Uses voiceover audio durations (the actual timing)
- Not based on estimated/animation timings

### ✅ Smart Title Extraction
- Prefers `sceneTitle` from script
- Falls back to first sentence of narration
- Truncates to 60 characters if needed

### ✅ Conditional
- **Long-form videos**: Timestamps added automatically
- **Shorts**: No timestamps (not supported by YouTube)

### ✅ Robust
- Validates scene count (≥3 required)
- Checks duration length
- Graceful fallback if generation fails

### ✅ YouTube Compliant
- First timestamp always `0:00`
- Format: `M:SS` or `H:MM:SS`
- Appended to description with emoji header

## 📝 Scene Title Guidelines (for AI)

The script generation prompt now instructs the AI to:
- Create concise scene titles (3-7 words)
- Capture the key concept of each section
- Make titles descriptive for navigation
- Avoid generic titles like "Scene 1" or "Part 2"

**Good Examples:**
- "Introduction to HTTP Statelessness"
- "The Vending Machine Analogy"
- "Benefits of Scalability"
- "How Cookies Work"
- "Session Management Techniques"

**Bad Examples:**
- "Scene 1" (too generic)
- "The comprehensive deep dive into the technical implementation details" (too long)
- "HTTP" (too short)

## 📌 Important Notes

1. **Shorts are excluded**: YouTube Shorts don't support chapters
2. **Minimum 3 chapters**: YouTube requires at least 3 timestamps
3. **First at 0:00**: YouTube enforces this requirement
4. **Title source priority**: `sceneTitle` > first sentence of narration
5. **Timing source**: Actual voiceover duration (most accurate)
6. **Graceful degradation**: If timestamps fail, video still uploads
