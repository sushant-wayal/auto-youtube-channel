# Branding Assets

Place your branding assets here for inclusion in generated videos.

## Supported Assets

### Logo
- **Filename**: `logo.png`
- **Format**: PNG with transparency recommended
- **Resolution**: At least 512x512px
- **Usage**: Overlaid on videos (typically bottom-right corner)

### Intro Video
- **Filename**: `intro.mp4`
- **Format**: MP4 (H.264 codec)
- **Duration**: 3-5 seconds recommended
- **Resolution**: 1920x1080 (Full HD)
- **Usage**: Played at the start of the video

### Outro Video
- **Filename**: `outro.mp4`
- **Format**: MP4 (H.264 codec)
- **Duration**: 5-10 seconds recommended
- **Resolution**: 1920x1080 (Full HD)
- **Usage**: Played at the end of the video (call-to-action, subscribe prompt, etc.)

## File Structure

```
assets/branding/
  ├── logo.png       (optional)
  ├── intro.mp4      (optional)
  └── outro.mp4      (optional)
```

All files are optional. The system will detect and use only the assets that are present.

## Tips

- Keep intro/outro short to maintain viewer engagement
- Use consistent branding colors across all assets
- Ensure logo has good contrast for visibility over video footage
- Test assets at different resolutions to ensure quality
